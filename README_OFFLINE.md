# デジタル_サボる時計 v0.1.0（完全オフライン版）

この v0.4.3 は、**外部ネットワーク（CDN / Google Fonts など）に一切依存しない**ように調整した版です。

## v0.3.0 変更点（カメラプレビュー）
- カメラプレビューの枠（緑の点線 / グレーの線）を削除
- 顔検出中に、顔を追いかける「緑の四角」を表示

## v0.2.0 変更点（iPad最適化 / フルスクリーンUI）
- iPad向けに **描画負荷を自動で軽量化**（DPR=1、液体バッファ解像度を下げる、描画パス削減、FaceDetectorの検出頻度を抑制）
- 画面上に **「フルスクリーン」ボタン**を追加（対応ブラウザはFullscreen APIを試行。iPadは基本「ホーム画面に追加」が最確実）
- UIを一時的に隠すボタンを追加（右上の「≡」で戻せます）


## v0.2.0 変更点（MediaPipe同梱）

- FaceDetector API ではなく **MediaPipe Tasks Vision（FaceDetector）** を同梱し、**完全オフラインの顔検出**で「見られている」判定を行います。
- 物体の動きに反応する Motion フォールバックは廃止（顔検出が初期化できない場合はシミュレーションで動作確認してください）。



## 変更点（v0.0.0 → v0.2.0）
- p5.js を **CDN から読み込むのをやめて、`libs/p5.min.js` として同梱**
- Google Fonts（Inter / Noto Sans）の読み込みを削除（＝通信ゼロ）
- 念のため `Content-Security-Policy` を追加し、外部通信が起きないように制限

## iPad での注意（カメラ）
ブラウザの `getUserMedia()`（カメラ）は **「安全なコンテキスト（Secure Context）」** が必須です。

iOS / iPadOS は環境によって挙動が変わるため、**カメラが動かない場合は「ファイル直開き」をやめて、ローカルサーバー経由**で開いてください。

### まず試す（簡単）
1) Files アプリでこのフォルダを開き、`index.html` を Safari で開く
2) 画面左上の **「① カメラを許可して開始」** を押す

### カメラが動かない場合（推奨：ローカルサーバー）
iPad 単体だけでやるなら、a-Shell mini 等で localhost サーバーを立てて Safari から開くのが手堅いです。

- a-Shell mini をインストール
- フォルダを a-Shell の領域にコピー（Files から共有 → a-Shell など）
- a-Shell でフォルダへ移動して実行：

```bash
python3 -m http.server 8000
```

- Safari で開く：
  - `http://127.0.0.1:8000/`

※ それでもカメラが許可できない場合は、Safari が **HTTPS を要求**している可能性があります。
その場合は「ネイティブアプリ化（SwiftUI + Vision で顔検知）」が最終的に一番確実です（次ステップで対応できます）。
